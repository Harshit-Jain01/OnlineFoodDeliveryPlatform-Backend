# QuickBite - Restaurant Service

The **Restaurant Service** manages the onboarding and details of restaurants on the QuickBite platform.

## Features
- **Restaurant Profiles**: Manages restaurant information such as name, address, contact details, and operating hours.
- **Restaurant Status**: Allows owners to toggle whether the restaurant is open or closed for orders.
- **Search & Filtering**: Provides APIs to search for restaurants based on location, cuisine, or rating.

## Technologies Used
- Java 17 & Spring Boot 3
- Spring Data JPA
- REST API
