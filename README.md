# QuickBite - Review Service

The **Review Service** manages customer feedback, ratings, and reviews for the QuickBite platform.

## Features
- **Submit Reviews**: Allows customers to rate and review their food and the overall restaurant experience.
- **Review Aggregation**: Calculates average ratings for restaurants and individual food items.
- **Review Moderation**: Admin capabilities to manage or remove inappropriate reviews.

## Technologies Used
- Java 17 & Spring Boot 3
- Spring Data JPA (or MongoDB)
- REST API
