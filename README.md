# QuickBite - Cart Service

The **Cart Service** handles the shopping cart functionalities for the QuickBite Online Food Delivery Platform.

## Features
- **Manage Cart Items**: Users can add, update, or remove items from their carts.
- **Restaurant Specific**: Ensures cart items are mapped accurately to the selected restaurant.
- **Cart Total Calculation**: Calculates subtotal, taxes, and final total amounts.
- **Clear Cart**: Empties the cart upon successful order placement.

## Technologies Used
- Java 17 & Spring Boot 3
- Spring Data Redis / JPA
- REST API
