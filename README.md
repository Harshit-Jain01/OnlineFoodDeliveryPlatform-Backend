# QuickBite - Auth Service

The **Auth Service** is a core component of the QuickBite Online Food Delivery Platform. It manages all user authentication, authorization, and security across the platform.

## Features
- **User Registration & Login**: Secure signup and login for Customers, Restaurant Owners, Delivery Agents, and Admins.
- **JWT Authentication**: Generates and validates JSON Web Tokens (JWT) for secure API access.
- **Role-Based Access Control (RBAC)**: Manages permissions based on user roles.
- **Secure Password Storage**: Encrypts and securely stores user credentials.

## Technologies Used
- Java 17 & Spring Boot 3
- Spring Security
- JSON Web Tokens (JWT)
- Spring Data JPA
- PostgreSQL / MySQL
