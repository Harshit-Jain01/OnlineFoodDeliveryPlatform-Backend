# QuickBite - Menu Service

The **Menu Service** is responsible for managing the food catalog for restaurants on the QuickBite platform.

## Features
- **Menu Management**: Allows restaurant owners to create, update, and delete menu items.
- **Categories**: Organizes food items into categories (e.g., Starters, Main Course, Desserts).
- **Availability Toggle**: Restaurant owners can mark items as in-stock or out-of-stock in real-time.

## Technologies Used
- Java 17 & Spring Boot 3
- Spring Data JPA
- REST API
