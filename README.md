# QuickBite - Payment Service

The **Payment Service** handles the financial transactions for the QuickBite platform.

## Features
- **Payment Gateway Integration**: Integrates with third-party payment gateways (e.g., Razorpay, Stripe).
- **Payment Processing**: Verifies and processes user payments for orders.
- **Webhook Handling**: Listens for asynchronous payment updates from the gateway.

## Technologies Used
- Java 17 & Spring Boot 3
- Razorpay API
- Apache Kafka
- Spring Data JPA
